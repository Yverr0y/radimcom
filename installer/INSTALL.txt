RADIMCOM - SDR receiver in the web browser
==========================================

Features
--------
- Up to 4 VFOs (A-D) side by side, each with its own SDR: RTL-SDR dongles and LimeSDR Mini.
  Fewer SDRs: the remaining VFO windows stay in place, greyed out ("NO SDR").
- VFO chaining: one dongle can serve several VFOs (e.g. one dongle for VFO A-D, or two
  dongles with two VFOs each); a chained VFO listens inside the band of its dongle.
- Transceiver-style screen: S-meter, 7-segment frequency displays, spectrum and waterfall
  (zoom 1x-32x), frequency shown on mouse hover, tuning by click, drag and mouse wheel.
- Modes AM, FM, WFM, LSB, USB, CW with adjustable filter width (drag the filter edge).
- WFM stereo and RDS (station name, RadioText, PI, PTY, clock).
- HF through an upconverter (configurable LO), warning when the manual CONV/BYPASS switch
  has to be changed.
- Squelch per mode, RF gain slider under each display (or AGC), audio ALC, automatic notch.
- AFI: audio frequency inversion (voice inversion scrambler / descrambler), frequency in SET.
- CUE: keep listening to other VFOs at a separate CUE level while one VFO is selected;
  MAIN and CUE volume faders, stereo level meter, MUTE.
- REC: records the audio of the selected VFO to a WAV file.
- Decoders: FT8, WEFAX (radio fax), CW (Morse), RTTY (auto shift/speed), SSTV (14 modes),
  ACARS (aircraft data link, VHF airband), CPDLC (controller-pilot messages in ACARS);
  optional daily log for each.
- DAB / DAB+ digital radio (Band III): station list, DLS text, slideshow (via welle-cli).
- Band buttons (HF/VHF/UHF ham, broadcast, airband, marine, PMR446, CB) and frequency
  memories with groups and favourites (import from SDR#).
- Frequency correction (ppm), bias-tee, sample rate, waterfall colours, S-meter calibration.
- TX with LimeSDR (optional, off by default, licence required): PTT = hold SPACE, FM test
  message or carrier; only in ham bands, CB 27 MHz and PMR446.
- Clock (local / UTC), all settings remembered per VFO.

Installation on a new PC
------------------------
1. Unzip RADIMCOM_install_v<version>.zip (e.g. RADIMCOM_install_v0.102.zip) - it contains
   the RADIMCOM folder; put it e.g. to C:\RADIMCOM (not into Program Files).
2. Connect the SDR dongles (RTL-SDR, LimeSDR Mini).
3. Run install.bat. It will:
   - check Python 3.9+ (if missing, it opens python.org; install it with "Add python.exe to PATH"),
   - install the Python packages into .venv (needs internet),
   - offer to install the USB drivers (Zadig for RTL-SDR, FTDI D3XX for LimeSDR) - see DRIVERS.txt,
   - run the SDR setup (setup_sdr.py): finds the dongles, assigns them to VFO A, B, C...,
     asks about an upconverter and ppm, and can write unique serial numbers into the EEPROM.
     Tip: to pick the right dongle for a VFO, simply UNPLUG it when asked and press Enter -
     the setup detects which one it was (then plug it back in). The USB order says nothing
     about which dongle is connected to which antenna or upconverter.
     To let one dongle serve several VFOs, type the letter of the VFO that already has it
     (e.g. A) instead of a device number.
   - create desktop shortcuts "RADIMCOM" and "RADIMCOM SDR setup".
4. Start the receiver with the RADIMCOM shortcut. The page opens at http://localhost:8434
   (the first start of a LimeSDR takes ~10 s because of calibration).

Different dongles later: close the receiver and run "RADIMCOM SDR setup" (setup.bat) again.
Old settings are moved to data\config_backup\.

All settings, memories, logs and saved images of this PC are kept in the data\ folder.

Transmitting (LimeSDR only): SET -> "Enable TX" (off by default). PTT = hold SPACE.
TX works only in ham 160-10 m, 6 m, 4 m, 2 m, 70 cm, 23 cm, CB 27 MHz and PMR446.

Change log
----------
(also in CHANGELOG.md)

Ver. 0.107
- AFI key (AUDIO group): audio frequency inversion - voice inversion scrambler /
  descrambler. The audio spectrum is mirrored around the inversion frequency
  (f -> 2*F - f), so the same setting scrambles and descrambles. All modes except WFM;
  remembered per VFO. Recording and decoders get the descrambled audio.
- SET: "AFI - inversion frequency (Hz)", 500-4000 Hz, default 1750 Hz (band up to 3500 Hz).
- HTTP API: new keys afi (true/false) and afi_hz in /api/set and /api/state.
- DAB / DAB+ digital radio: DAB button in the OTHER band group. The VFO goes to 2.048 MS/s
  on a Band III channel (5A-13F, default 12C); the DAB+ card shows the ensemble, SNR and the
  station list; click a station to listen, with DLS text and slideshow picture. Decoded by
  welle-cli (welle.io, GPLv2+) in lib\dab (see lib\dab\README.txt), fed by RADIMCOM over a
  local rtl_tcp connection. Turns ACARS / VDL2 off; DAB again, another band button or OFF ends DAB.
  RTL-SDR only. REC does not record DAB audio.
- HTTP API: dab, dab_channel in /api/set and /api/state; GET /api/dab, /api/dab/audio/<sid>,
  /api/dab/slide/<sid>.
- WEFAX slant correction: SLANT field (ppm, -3000 to 3000) and ALIGN key in the WEFAX card (click two
  points on a line that should be vertical). Corrects the sample clock error of the VFO's SDR, also
  straightens the image received so far, kept after a restart. HTTP API: slant_ppm in /api/wefax.
- Passband label in the spectrum has two rows: tuned frequency, then demodulation and bandwidth.

Ver. 0.106
- VFO chaining: one dongle can serve several VFOs (e.g. one dongle for VFO A-D, or two
  dongles with two VFOs each). In the SDR setup type the letter of an earlier VFO (e.g. A)
  to share its dongle. The chained VFO has its own frequency, mode, decoders and audio,
  and receives inside the band of the owner VFO (centre +- half the sample rate):
  green CHAIN flag instead of the USB icon; outside the band it is silent with an orange
  OOR flag ("out of range VFO-A"). Gain, ppm, bias-tee and sample rate are shared with the
  owner VFO. VDL2 and TX only on the owner VFO.
- ATN CPDLC (VDL2): click a message to see all decoded fields (CPDLC message first, then
  the VDL2 frame: addresses, X.25, CLNP, COTP). Click again to collapse.
- Direction arrows coloured: down (from the aircraft) green, up (from the ground) orange.
- VDL2 key greyed out on a LimeSDR VFO (VDL2 runs on RTL-SDR only).
- Message filter: click the ACARS / CPDLC / ADS-C tags at the top of the card
  to show only those messages; "FILTER ON" shows it is active, x shows all again.
- ACARS / VDL2 card: only the message list scrolls, the header and filters stay in place.
- ATN CPDLC: the Aircraft column waits for the ADS-B lookup instead of rewriting the ICAO address.
- ATN ADS-C (over VDL2) decoded like FANS ADS-C: position, altitude, track, speed, wind,
  temperature, next waypoints, planned trajectory. Purple ADS-C tag.
- Tags unified: ATN CPDLC messages have the green CPDLC tag (Description says ATN CPDLC).
- The tag has its own first column "Type" in the message table; fixed column widths
  (the layout does not jump when a filter is switched).
- New Country column: flag of the country of registration from the aircraft's ICAO address.
- Aircraft column renamed Callsign; new columns ICAO, ACFT type, Model, FL, Speed;
  Flight moved next to Country (position no longer shown).
- Memory names on the spectrum: a green marker at the top points to each memory's frequency,
  with a name tag under it (hover = full name, frequency, mode; click = recall the memory).
- All decoder cards (FT8, ACARS / VDL2, CW, RTTY, WEFAX, SSTV) have one design: the card fills
  the DECODERS tab, header and settings stay in place, only the content box scrolls.
- The page scales with the browser window (and ignores browser zoom): everything keeps its
  layout and just gets bigger or smaller.
- CW decoder more reliable with weak signals, fading (QSB) and static crashes (QRN):
  automatic minimum threshold from the measured noise floor (no random characters from
  noise), mark level that follows fading, noise blanker for static crashes, starts on
  weaker signals, speed estimate no longer locks onto noise. Simulated tests: error rate
  on average 40 % -> 15 %. ALC does not affect the CW decoder (it has its own level control).
- Band plan on the spectrum axis extended (local table static\bandplan.js, Europe / ITU
  Region 1): military airband, VOR/ILS, DME, ADS-B 1090, SSR 1030, TETRA, VHF low/military,
  DAB, DVB-T/T2, LTE 700/800, GSM-900/1800, UMTS 2100, LPD433, SRD 868 / LoRaWAN, Wi-Fi 2.4,
  weather satellites, radiosondes (400.15-406 MHz, L-band), COSPAS-SARSAT 406, GNSS, Inmarsat,
  Iridium, marine VHF, AIS, NAVTEX, 2182 kHz, paging 169, DCF77, NDB, LW / MW broadcast,
  13 cm ham. Narrow bands drawn over wide ones; hover the axis for the band description.
- Memory import / export (MEM -> Import / export): IMPORT SDR# reads frequencies.xml from the
  SDR# installation folder and its profile subfolders (e.g. Instances\Profile1); duplicates are
  skipped. EXPORT downloads the starred memories or the selected group (All = every memory)
  as a JSON file with one click.
- HTTP API description (control the receivers from scripts): API\API.md.
- LimeSDR TX only in allowed bands (checked by the receiver): ham 160-10 m, 6 m, 4 m, 2 m,
  70 cm, 23 cm, CB 27 MHz, PMR446; the whole signal (+-5 kHz) must be inside the band.
  Retuning during TX ends the transmission.
- Red TX disclaimer in SET; Enable TX asks to accept it (licence required, operator fully
  responsible). TX enabled by an older version stays off until it is accepted.
- MIT licence (LICENSE file) with a radio transmission notice.
- Remaining Slovak comments in the code translated to English.

Ver. 0.105
- VDL2 decoder (VDL Mode 2, 136.725-136.975 MHz): digital data link with most airline
  ACARS over Europe and the European ATN CPDLC. VDL2 key under DECODE: the VFO goes to
  2.1 MS/s around 136.850 MHz, all five channels decoded at once. Uses dumpvdl2 2.7.0
  (GPLv3, lib\vdl2\, see lib\vdl2\README.txt) as a separate program.
- ACARS from VDL2 decoded like classic ACARS (CPDLC, ADS-C, ADS-B lookup, logs).
  European ATN CPDLC in a compact form (e.g. "dM6 REQUEST FL360", "dM0 WILCO").
- ADS-C decoder: position reports, track, speed, wind, temperature, predicted route,
  projected intent, contract requests.
- One card for all aircraft messages: ACARS and VDL2 keys open the same card, the CPDLC
  key is gone. Coloured tags ACARS / CPDLC / ADS-C / ATN CPDLC. One LOG for both logs.
- ATN CPDLC: registration, type, position and callsign looked up on ADS-B by the
  aircraft's ICAO address (the only aircraft identifier in ATN messages).

Ver. 0.104
- CPDLC decoder (FANS-1/A, ARINC 622): controller-pilot messages carried in ACARS
  (labels AA/BA/H1) decoded to the standard text, e.g. "CLIMB TO AND MAINTAIN FL350",
  "AT VANDA CONTACT CHRISTCHURCH CONTROL 128.100 MHz", position reports with fixes,
  ETA, winds and temperature. Message number (MIN), answered message (MRN), ground
  station, CRC check; long messages split into several ACARS blocks are joined.
- CPDLC card with its own CPDLC key under DECODE; works with the ACARS card off.
  Decoded CPDLC text is also shown in the ACARS card. Click a message for the raw text.
- CPDLC daily log: data\acars\cpdlc_YYYY-MM-DD.txt (UTC) when LOG is on.

Ver. 0.103
- Settings, memories, logs, saved images and backups moved to the data\ folder
  (program files stay in the main folder). Older installations: the files are moved
  to data\ automatically at the first start.

Ver. 0.102
- Decoders (FT8, WEFAX, SSTV, ACARS) moved to a second tab DECODERS next to SPECTRUM,
  no more scrolling down. The tab shows the number of running decoders and a green dot
  when something new arrives; turning a decoder on opens the tab.
- The open tab (SPECTRUM / DECODERS) is remembered for each VFO and restored when switching VFO;
  a VFO without a saved tab opens DECODERS when a decoder is running on it.
- RTTY decoder (Baudot/ITA2) with automatic detection of shift (90-1000 Hz), speed
  (45.45/50/75/100 Bd) and polarity; each can also be set by hand. E.g. amateur RTTY
  45.45 Bd / 170 Hz, DWD weather 50 Bd / 450 Hz (4583, 7646, 10100.8 kHz).
  Text shown like on an old green phosphor terminal.
- CW decoder is now a card in the DECODERS tab; CW and RTTY text fills the whole tab.
- LOG checkbox in every decoder card: daily log logs\<decoder>_YYYY-MM-DD.txt (UTC, one line
  per message; WEFAX/SSTV log the names of saved images). ACARS logs to acars\ only when LOG is on.

Ver. 0.101
- ACARS decoder (VHF airband, 131.725 MHz etc.): coherent MSK demodulation, CRC check,
  message description in plain English, long messages collapsed (click to expand).
- ACARS: aircraft type and position looked up on ADS-B (adsb.fi / adsb.lol), shown in blue;
  click the registration or flight to open the live map.
- ACARS daily log: acars\acars_YYYY-MM-DD.txt (UTC), including the ADS-B data.
- SQUELCH slider under RF GAIN for every VFO (dimmed in modes without squelch).
- FM filter widths 500 Hz - 50 kHz (buttons 0.5 / 3 / 6 / 12 / 25 / 50 kHz).
- Grey RDS logo when no RDS is received; inactive ALC/SQL flags no longer larger.
- Setup: upconverter LO is checked (30-1000 MHz, Hz input converted); LO/ppm can be fixed
  in SET even when the dongle is in error.
- FT8 works without PyAudio (newer Python); a missing PyFT8 no longer stops the receiver.
- Installer shows the download progress of the Python packages.
